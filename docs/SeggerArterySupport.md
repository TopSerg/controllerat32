## Добавление поддержки микроконтроллеров `Artery` в программатор Segger JLink.
1. Установить последнюю версию ПО для программатора версия 6.5 и выше
2. Установить поддержку микроконтроллеров `Artery` согласно [Artery FAQ0008](https://www.arterychip.com/file/download/135)
3. Применить решение описанное в [Artery FAQ0132](https://www.arterychip.com/file/download/376).
Файл со списком MCU в [архиве](https://www.arterychip.com/file/download/377)
